# Vue Test Project

A minimal Vue 3 + TypeScript + Vite app for trying reactivity, single-file components, and hot module reload.

## Stack

- Vue 3 (`<script setup>`)
- TypeScript
- Vite

## Run locally

```bash
npm install
npm run dev
```

Then open [http://127.0.0.1:4521](http://127.0.0.1:4521).

## Scripts

| Command           | Description              |
| ----------------- | ------------------------ |
| `npm run dev`     | Start the Vite dev server |
| `npm run build`   | Type-check and production build |
| `npm run preview` | Preview the production build |

## Project layout

```
src/
  App.vue          # main interactive demo
  main.ts          # app bootstrap
  style.css        # global styles
  assets/          # static assets
```
